# ♟ Chess Game (C#)

## 📌 Overview

This project is a chess game developed in C# with the goal of practicing **object-oriented programming**, game logic, and problem-solving skills.

The focus of the project is on modeling game rules and interactions rather than UI complexity.

---

## 🧱 Design Approach

The game logic is structured using object-oriented principles:

- Each chess piece is represented as a class
- Game rules are enforced through encapsulated logic
- Board state is managed centrally

---

## 🔧 Tech Stack

- C#
- .NET

---

## 🧠 Key Concepts Demonstrated

- Object-Oriented Programming (OOP)
- Encapsulation and abstraction
- Game state management
- Rule-based logic
- Clean separation between game logic and execution flow

---

## 🎯 Project Purpose

This project was built as a learning exercise to improve reasoning about complex rules and to apply OOP concepts in a non-trivial problem space.
